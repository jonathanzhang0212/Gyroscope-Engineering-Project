# Gyroscope-Engineering-Project
Designed and built a mechanical gyroscope with a focus on rotational stability and performance. Conducted hands-on manufacturing, assembly, and testing to ensure sustained rotational motion for over two minutes. Applied concepts from dynamics and system analysis to optimize performance.
